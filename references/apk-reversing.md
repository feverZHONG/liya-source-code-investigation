# APK 逆向分层

> 从 SKILL.md 拆出（2026-09-04 拆薄）。调查对象是 APK 时先看这张表。

| 层 | 做什么 | 工具 | 难度 |
|:--|:--|:--|:--|
| 解包 | 拿资源/文件（APK 本质是 zip） | unzip | 简单 |
| 看代码 | dex → Java 源码 | jadx | 入门（混淆后是耐力活） |
| 重打包 | 改完再签 | apktool + apksigner | 中（v2 签名改字节必炸） |
| 脱壳 | 对付加固壳 | frida/BlackDex/Youpk… | 玄学，无固定流程 |

**调查别人项目的魔改包时，多数情况 clone 源码比拆 APK 更快更有信息量——先看有没有开源，再决定拆包。**
